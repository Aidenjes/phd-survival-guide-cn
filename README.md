# 博士生存指南

一本面向中国博士生的开源科研生存手册：解释科研系统的运行方式，记录其中不合理甚至病态的现象，并提供可执行的识别、应对与改进方法。

本项目试图回答三个问题：

1. 中国博士培养和科研系统实际上如何运行？
2. 博士生如何建立一套可重复的科研工作方法？
3. 当研究、导师协作或毕业进度出现问题时，如何进行理性判断和行动？

这里不会提供“快速毕业秘籍”，也不会把个体经历概括为所有人的处境。
我们希望通过机制解释、工作流程、情景案例和实用模板，
帮助博士生减少信息差与焦虑，更有意识地完成科研训练。

## 我们为什么讨论病态科研环境
科研训练不应以羞辱、恐惧、无边界劳动或学术不端为代价。

本项目不仅介绍论文写作和科研方法，也关注博士培养中的权力失衡、
规则不透明、成果分配不公、情绪控制、过度劳动及学术诚信压力。

讨论这些问题并不是为了把所有导师、课题组或高校描述为同一种样子，
也不是为了鼓励对立。我们的目的，是识别具体行为及其制度条件，
减少信息差，并帮助博士生作出更安全、更理性的判断。

本项目坚持以下原则：
1. 批评行为和机制，不进行人身攻击；
2. 区分可核查事实、匿名经历、机制分析和作者观点；
3. 不公开能够识别当事人的隐私信息；
4. 不将单一个案直接概括为整个学科或群体；
5. 对严重指控要求提供可靠证据，并保留不予收录的权利。
